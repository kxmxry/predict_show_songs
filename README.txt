# eden-show-songs

פרויקט לחיזוי שירים שיופיעו בהופעה של עדן בן זקן, על סמך מידע שנאסף מהופעות קודמות.

## 🧠 מטרות
- לחלץ מידע משיחות / תמלולים של הופעות.
- לזהות אילו שירים בוצעו, ובאיזה הקשר (דואט, מדלי וכו').
- להשתמש ב-GPU כדי להאיץ את תהליך האיסוף והניתוח.

## 🛠 איך להריץ
1. צור סביבת עבודה:
    ```bash
    python -m venv venv
    source venv/Scripts/activate  # ב-Windows
    pip install -r requirements.txt
    ```

2. הרץ את הקוד הראשי:
    ```bash
    python main.py
    ```
